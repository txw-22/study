## 2. 학습한 개념

### `print()`란?

Python에서 괄호 안의 값을 터미널에 출력하는 함수다. JavaScript의 `console.log()`와 비슷한 역할을 한다.

```python
print("Hello, Python!")
print("파이썬 공부 1일차")
```

실행 결과:

```text
Hello, Python!
파이썬 공부 1일차
```

### 숫자 계산과 문자열 출력

```python
print(10 + 20)      # 30
print("10 + 20")    # 10 + 20
```

- 따옴표 **밖**의 `10 + 20`은 숫자 계산이 된다.
- 따옴표 **안**의 `"10 + 20"`은 문자열이므로 그대로 출력된다.
- `#` 뒤의 내용은 한 줄 주석이며, 코드 실행 결과에 영향을 주지 않는다.

## 3. 직접 작성한 코드: 자기소개 출력

**조건:** `print()`만 사용하고, 변수와 반복문 없이 총 6줄 출력하기.

```python
print("===== 자기소개 =====")
print("이름 : txw ")
print("공부 언어 : Python")
print("공부 시작일 : 2026-11-17")
print("올해 목표 공부일 : 30일")
print("====================")
```

실행 결과:

```text
===== 자기소개 =====
이름 : txw 
공부 언어 : Python
공부 시작일 : 2026-11-17
올해 목표 공부일 : 30일
====================
```

**코드 리뷰:** 조건을 모두 충족했고 정상 실행되었다. `"txw "`처럼 따옴표 안에 넣은 마지막 공백도 출력에 포함되므로 출력 형식을 맞출 때 주의하자.

## 4. 실행 환경에서 겪은 문제와 해결

처음에는 `python --version`을 입력해도 버전 번호가 아니라 `Python`만 나타났다. `py --version`은 명령어를 찾지 못했고, `where.exe python`은 `WindowsApps\python.exe`를 가리켰다.

Python Install Manager를 통해 CPython 설치를 진행한 뒤, VS Code 터미널에서 다음 명령어로 `.py` 파일 실행에 성공했다.

```powershell
python .\python\day01.py
```

> 위 오류는 Windows의 앱 실행 별칭과 관련되었을 가능성이 있었지만, 당시 정보만으로 단정할 수는 없다.
